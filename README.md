# ShopKeeper — Introductory Customer Landing Page & Presentation Deck

A high-performance, dark-mode introductory landing page and interactive presentation deck for potential ShopKeeper customers, built directly from the UI design reference in `Project design/`.

## Features
- **Design Fidelity**: Exact reproduction of the aesthetic from `Project design/` (`1.jpg` through `5.jpg`):
  - **Slide 01**: Intelligent SaaS Growth Platform (Hero showcase)
  - **Slide 02**: The Operational Challenge (Efficiency, Visibility, Productivity metrics)
  - **Slide 03**: Operational Efficiency Solved (Speed, Visibility, Automation & Workflow Optimization)
  - **Slide 04**: Growth And Retention (Cinematic banner, contact pillars, demo request)
- **Interactive Deck Mode**:
  - Slide pill indicator (`Slide [01]`) with instant chevron navigation
  - Keyboard shortcuts (`←` / `→` / `Space` / `PageUp` / `PageDown` / `Home` / `End`)
  - Fullscreen toggle (`F`)
  - Touch swipe gestures for tablets and mobile devices
  - Animated progress bar and bottom dot indicator
  - Autoplay mode with auto-advancing slides
- **Continuous Scroll Mode**: Toggle between executive presentation deck view and standard scrollable landing page view with one click.
- **Interactive Demo Booking Modal**: Glassmorphic modal with instant feedback and toast notifications.
- **Zero-Dependency Architecture**: Pure HTML5, Vanilla CSS, and modern ES6 JavaScript.

## How to Run Locally
Run directly with Node.js:
```bash
node server.js
```
Then open [http://localhost:8080](http://localhost:8080) in your browser.
